# Kiln Core Execution Authorization 007

Core 007 is the authority boundary between planning and execution.

A plan is not executable merely because it exists.

Authorization requires:

- stable plan identity
- shared Test Library occurrence identity
- shared content identity
- repository root and test path
- runner
- attack surface
- evidence provenance
- supported recovery topology
- compatible execution topology

Failure of any gate leaves execution_authorized=false.

Core 007 still executes nothing.
