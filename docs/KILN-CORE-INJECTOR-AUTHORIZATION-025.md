# Kiln Core Injector Proof Authorization 025

Core 025 chooses at most one bounded injector-proof candidate per attack surface.

Authorization requires:

- CONTRACT_ONLY surface readiness
- a proven untouched baseline
- target-native carrier evidence
- deterministic ranking

Authorization does not imply that the candidate is a valid injector.

It grants one trial whose purpose is to prove or reject the carrier.

No target mutation occurs during Core 025.
