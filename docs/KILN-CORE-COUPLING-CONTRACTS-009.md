# Kiln Core Coupling Contracts 009

Core 009 formalizes the difference between pressure injection and behavioral coupling.

A pressure contract cannot establish resistance until Kiln proves that the target actually observed the pressure.

Every coupling contract requires:

- a baseline observation
- a pressured observation
- a target-native observation method
- evidence of behavioral or state exposure

All coupling contracts begin coupling_proven=false.

No target is executed during Core 009.
